# 성모상 3D 모델 만들기 (Google Colab, 무료)

준비물: `rosarium_statue3d.ipynb` 파일, 조각상 사진 6장(jpg) 또는 사진을 묶은 `mary_marble_views.zip`

1. PC 브라우저에서 **https://colab.research.google.com** 접속 (구글 로그인)
2. 처음 뜨는 창에서 **업로드** 탭 → **찾아보기** → `rosarium_statue3d.ipynb` 선택
   (창이 안 뜨면 메뉴 **파일 → 노트 업로드**)
3. 메뉴 **런타임 → 런타임 유형 변경** → 하드웨어 가속기 **T4 GPU** → **저장**
4. 메뉴 **런타임 → 모두 실행** (`Ctrl + F9`). "Google에서 작성하지 않은 노트" 경고가 나오면 **무시하고 계속**
5. 잠시 뒤 **「2. 사진 올리기」** 칸에 **파일 선택** 버튼이 생기면 jpg 6장을 한꺼번에 선택 (또는 zip 1개)
6. 창을 열어 둔 채 **약 20~35분** 기다리기 (설치 10~15분 + 생성/변환)
7. 끝나면 GLB 2개가 자동 다운로드됩니다. 브라우저가 "여러 파일 다운로드"를 물으면 **허용**
   - `mary_statue_trellis.glb` (기본), `mary_statue_trellis_mobile.glb` (앱용 경량)
   - 자동 다운로드가 안 되면 왼쪽 폴더 아이콘 → `rosarium/output` → 파일 옆 **⋮ → 다운로드**
8. 받은 GLB 파일(특히 `_mobile.glb`)을 **채팅에 올려 주세요**

문제가 생기면
- "GPU 사용량 한도" → 무료 사용량을 다 쓴 것입니다. 몇 시간~하루 뒤에 다시.
- 설치 중 빨간 오류 → **런타임 → 세션 다시 시작** 후 **모두 실행** (사진은 다시 올리기)
- "GPU 메모리 부족" → 노트북이 자동으로 사진 3장, 그다음 대체 방법(TripoSR)으로 다시 시도합니다.
- 결과 모양이 이상하면 노트북 맨 위 설정의 `SEED` 숫자를 바꿔서 다시 실행
