# 로사리움 성당 미술품 원본 확보용 패키지
확인일: 2026-11-15

**중요: 현재 작업 환경의 외부 파일 다운로드 차단으로 JPG 원본은 ZIP에 포함되지 않았습니다.** 원본 URL과 다운로드 스크립트가 포함되어 있습니다.

## Claude 전달 지시
1. manifest.json을 읽고 `python download_originals.py`를 인터넷 사용 가능한 환경에서 실행하라. Python 3 및 Pillow 필요(`python -m pip install Pillow`).
2. 기본값은 15개 후보 전부 다운로드. A안 9개만 받으려면 `python download_originals.py --primary-only`.
3. 다운로드한 원본 JPEG를 originals/에 보관하고 파일별 실제 픽셀 크기 및 SHA-256을 검증한다. 실패/불일치 파일은 적용하지 않는다.
4. 02 기둥의 성모는 미확보 상태이며 CC BY-SA 단독 사진으로 대체하지 않는다.
5. 기존 앱의 모델·UI·기도 기능을 변경하지 말고 필요한 자산만 적용. 조각·제대·무덤 사진은 3D 모델 제작 참고용이며 평면 이미지로 대체할 것인지 별도 판단. 모자이크는 후진 곡면 UV 기준으로 재구성 검토. 피렌체 회화는 벽면 텍스처 후보.
6. 원본은 변환하지 말고 별도 배포용 텍스처(WebP/KTX2 등)를 만든다. CC BY 출처, 라이선스 링크, 변경사항을 앱에 표시.
7. PDM 및 PD-Art의 관할별 저작권 효력, 이탈리아 문화유산 관련 별도 제한을 배포 전 검토. 특히 01/03/07은 검토 전 배포 보류. PD-Art도 별도 권리 검토.

## 파일
- manifest.json: 원본 URL, 파일 페이지, 저작자, 해상도, 라이선스, 주의사항
- manifest.csv: 동일 정보 표
- gallery.html: 인터넷 연결 상태에서 이미지 미리보기 및 원본 링크 제공(이미지 내장 아님)
- download_originals.py: 원본 다운로드, 크기 확인, 해시 기록

A/B는 추천 및 대안이지 전체 커먼즈에서 절대 최고 해상도라는 뜻은 아님. 픽셀 수뿐 아니라 정면성·작품 전체 포함 여부·권리 조건을 고려. 원본 URL은 커먼즈 파일명 기반 저장 경로 규칙으로 구성했으며 파일 페이지의 Original file 링크로도 접근 가능. 모든 사진의 촬영 각도 또는 별도 법적 제한은 완전 검증되지 않음.
