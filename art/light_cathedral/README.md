# 빛의 성당 — 그림 자산 원본 (2026-11-24)

사용자가 제미나이(Gemini)로 만든 **AI 생성 그림**(실제 성당의 창을 본뜨지 않은 새 디자인). 저작권 문제 없는 자체 생성물.

- `src/glass_{joyful,luminous,sorrowful,glorious}_sheet.webp` — 묵주기도 신비별 랜싯 창 5개를 한 장에 그린 시트(2000×1116)
- `src/glass_rose_marian.webp` — 정면 장미창(성모자, 천사, 성모 상징), 1500×1500
- `windows/<신비>_<1~5>.webp` — 시트에서 창 하나씩 잘라 낸 것(뾰족 아치 위 끝 ~ 아래 장식띠). 순서는 각 신비의 1~5단
  - 환희: 수태고지 · 방문 · 탄생 · 성전 봉헌 · 성전에서 찾으심
  - 빛: 요르단 강 세례 · 카나 혼인 잔치 · 하느님 나라 선포 · 거룩한 변모 · 성체성사 제정
  - 고통: 겟세마니 · 매 맞으심 · 가시관 · 십자가 지심 · 십자가 죽음
  - 영광: 부활 · 승천 · 성령 강림 · 성모 승천 · 성모 대관
- 3D 성당 빌더가 쓸 때는 `assets/church/` 의 창 질감 규칙(GLASS_DEV_PIPELINE.md)대로 줄이고 알파를 만든다.
- 오른쪽 아래 Gemini 워터마크는 잘라 낸 창 안에는 들어가지 않았다(시트 원본에는 있다).
