# 십자가의 길(14처) — 문구 검수표

> **상태: 사제·교구 검수 필요.** 아래 문구는 모두 앱 개발 중에 새로 쓴 초안이다. 교리·표현을 본당 신부님(또는 교구)께 확인받기 전까지는 '검수 전'으로 본다.

- **원본 파일**: `data/stations_of_cross.json` (이 표는 그 파일에서 옮겼다). 고친 뒤 `python3 tools/stations/build_stations.py` 를 실행하면 앱(`lib/domain/stations_of_cross_data.dart`)과 성당 3D(`assets/church/cross_data.js`)가 함께 바뀐다. `--check` 와 `flutter test test/stations_of_cross_test.dart` 가 일치·명칭 스냅샷을 확인한다(명칭을 고치면 시험의 `_titles` 도 함께 고친다).
- **저작권 원칙**(ART_REFERENCES.md §4): 한국천주교주교회의 『가톨릭 기도서』의 십자가의 길 기도문과 응답 구절은 옮기지 않았다. 성경은 **장·절 표시만** 적고 본문(『성경』 2005 번역)을 인용하지 않았다. 묵상은 복음 사건을 풀어 쓴 2문장 + 한 줄 청원이다.
- **처 명칭**: 전통 14처의 일반 표기. 『가톨릭 기도서』 표기와 글자 하나까지 같은지는 확인하지 않았다(검수 항목).
- **전승의 처**: 3·4·6·7·9처는 성경에 직접 나오지 않는 교회 전승이며 앱에서 '전승'으로 표시한다. 제15처(부활)는 넣지 않았다.

## 검수 때 물을 것
1. 처 명칭이 소속 교구에서 쓰는 표기와 같은가(예: '키레네 사람 시몬이 예수님을 도와 십자가를 짐').
2. 환호 '우리는 당신을 경배하며 찬미하나이다…'를 이 형태로 써도 되는가, 아니면 교구가 쓰는 응답으로 바꿀 것인가(공식 번역문이면 사용 허락이 필요).
3. 전승의 처(3·4·6·7·9) 서술 방식, 12처의 '잠시 침묵' 안내, 13처 '전승은 … 전합니다' 표현.
4. 묵상 분량(지금 2문장 + 청원 1줄)이 적당한가, 더 짧게 또는 길게.
