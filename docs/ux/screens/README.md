# 화면 스크린샷 묶음 (외부 UX 검토용)

- 기준: 360x800 dp 폰, 배율 2배(720x1600 px), 한국어, Pretendard 글꼴, Material 3 테마(`AppTheme.light()` / `dark()`).
- 만든 방법: Flutter 위젯 테스트로 실제 화면 위젯을 그대로 그림(가짜 설정·메모리 기록·가짜 성당 서버 사용). 상태 표시줄은 없음.
- 성당 화면(10~13)의 3D 배경은 실제 3D 장면을 Playwright로 따로 찍은 정지 사진을 배경 자리에 넣은 것이다. 위의 버튼·조이스틱·시트·기도 카드는 실제 앱 위젯이다.
- 3D 사진 속 아바타는 기본 모습(초록 옷)이라 설정에 저장한 아바타와 다를 수 있다.
- 용량 때문에 사진이 많은 4장(10, 11, 12번과 3d_* 사진)은 JPG(고화질)로 저장했다. 나머지는 PNG.
