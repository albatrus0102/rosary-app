# 성당 구조도 대조 H-1 — 로마 4대 성전 (stpeter · lateran · maggiore · stpaul)

> 조사·대조 문서다. **이 단계에서 씬·앱 코드는 고치지 않았다.** 다음 단계의 구현자가 이 문서의 '수정 지시서'대로 고친다.
> 작성: 2026-11-15. 짝 문서: `STRUCTURE_AUDIT_OTHERS.md`(H-2, 나머지 성당).

## 0. 방법과 표기

**실제 구조** — 출처를 직접 열어 확인했다(§6 출처 목록에 '직접 확인'/'못 엶' 표시). 평면도는 섬네일을 내려받아 눈으로 보고, 축척 막대나 도면에 적힌 치수로 픽셀을 미터로 바꿔 쟀다(오차 ±1~2 m; '도면 실측'이라고 적은 값이 그것이다). 내려받은 그림은 scratchpad 에만 두었다.

**모델 측정** — 빌더를 Node(vm)에서 그대로 돌려 쟀다. Playwright·브라우저는 쓰지 않았다.
- `node tools/church_web/church_plan.mjs <id>` (이번에 추가): **걷기 지도**(충돌체로 막힌 칸 `#`, 걸을 수 있는 칸 `.`, 원형 충돌체 `o`, 높은 바닥 `^`, 좌석 `s`, 스폰 `S`, 촛불대 `c`) + 기둥 줄(같은 x 줄의 z 목록) + 큰 충돌체·높은 바닥 표. 실제 평면도와 '갈 수 있는 곳'을 견주는 도구다.
- `node tools/church_web/church_structure.mjs <id>` (H-2 작성): 키트 호출(제대·계단·바닥·궁륭 …)과 조형 bbox.
- `node tools/church_web/church_openings.mjs --all` (기존): 창 개구부 수.
- 그 밖의 치수는 빌더 소스의 상수(줄 번호를 적었다).

**단위** — '앱 m' = 실제 m × scalePercent/100. 좌표: 입구 +z, 제대 −z, 위 +y.

**판정** — 일치 / 허용(축척·단순화 감안) / **불일치-구조**(위상이 다름) / **불일치-비례** / 모델에 없음 / 실제에 없음(모델이 지어냄) / 의도적 축약.
**우선순위** — **P0** 눈에 띄는 구조 오류(평면 위상이 다름) / **P1** 비례·중요 설치물 / **P2** 세부. **작업량** — S(반나절 이하) / M(하루 안팎) / L(이틀 이상).

**네 성당 공통으로 구현자가 지킬 것**
1. 고칠 파일은 `assets/church/ch_<id>.js` 하나(+ 레이아웃을 바꾸면 `node tools/church_web/export_layouts.mjs` 로 `server/church/src/layouts.json` 갱신). 키트(`kit.js`)는 건드리지 않는다.
2. 고친 뒤 반드시: `node --test "tools/church_web/*.test.mjs"`(레이아웃·14처·전례·룩·창 배치 시험), `node tools/church_web/church_plan.mjs <id>`(걷기 지도에서 새 통로가 열렸는지, 막다른 틈이 없는지), `node tools/church_web/church_openings.mjs --check`(`data/glass_windows/<id>.json` 의 개구부 key·좌표가 그대로인지 — 창을 옮겼다면 그 JSON 과 `glass_placements.js` 를 같이 고친다).
3. CPU 가 한가해진 뒤: `node tools/church_web/shot.mjs <id> --pos x,z --yaw …` 로 지시서에 적은 지점의 전/후 화면, `node tools/church_web/e2e.mjs`. 콘솔 에러 0.
4. 성능 예산(BUILDER_API §5·§7.5): 정점 < 250k, 충돌체 < 300, 점광원 1개. 고치기 전후로 `__church.world.stats` 의 정점·메쉬 수를 적어 둔다. 새 조형은 기존 배치(`ctx.solid`, `ctx.surfBatch(...)`)에 넣어 draw call 을 늘리지 않는다.
5. 14처(`way_cross.js`)는 벽 후보에서 자리를 자동으로 고른다 → 벽을 뚫거나 옮기면 14처 자리가 바뀔 수 있다. `way_cross.test.mjs`·`stations.test.mjs` 와 `shot.mjs` 로 14처가 벽 안으로 들어가거나 새 개구부 앞에 걸리지 않는지 본다.
6. 전례 장식 기준점(`liturgy.js` 40~67행의 성당별 `altar`/`L`/`R`/`pots`)은 제대 좌표에 묶여 있다. 제대를 옮기면 같이 고친다(이 문서의 지시는 제대를 옮기지 않는다 — 예외는 따로 적었다).

### 1.4 수정 지시서 (stpeter)

대상 파일: `assets/church/ch_stpeter.js`. 돔 중심 (0, −9). 아래 좌표는 앱 m. `R_OUT = 16.7`(회랑 바깥벽 안쪽 면; 실제 약 45 m).

**① 돔 피어 둘레 회랑과 모서리 경당 4곳 (P0, L)** — 좌우 대칭(`s = ±1`)으로 짓는다.
1. 새 공간 넷(한쪽당):
   - 동쪽 모서리 경당(+x 그레고리오 / −x 클레멘스): x 10.95…16.7, z 1.95…7.75.
   - 동쪽 통로: x 10.95…16.7, z −4.75…1.95 (돔 피어 바깥 면을 따라감).
   - 서쪽 통로: x 10.95…16.7, z −19.95…−13.25.
   - 서쪽 모서리 경당(+x 성 미카엘·페트로닐라 / −x 기둥의 성모): x 10.95…16.7, z −25.75…−19.95, 그리고 그 안쪽 칸(후진 팔 첫 칸의 옆) x 4.25…10.95, z −25.75…−19.95 (지금은 빈 허공이다).
2. 측랑 바깥벽(479~494행의 `ExtrudeGeometry` 벽): 아치 4번 칸(`ARCHZ[3] = 4.2`)에도 구멍을 낸다. 경당 구멍(폭 3.2)이 아니라 신랑 아케이드와 같은 큰 아치(폭 4.5, 시작선 6.25). 524행 바깥벽 충돌체는 z 6.45…35.2 로 줄인다.
3. 익랑 벽(820~826행): 상자·충돌체·엔타블러처·벽기둥의 x 범위를 10.95…21.25 → **16.7…21.25** 로 줄이고(z=−4.75, −13.25 양쪽), 뚫린 10.95…16.7 구간에는 아치(폭 4.8, 시작선 6.25) + 아치 위 벽(시작선 12.35 까지)을 `extrude`+`archHolePath`(159~170행 도우미)로 짓는다. 13.9 의 벽기둥·16.0 의 벽감은 18.1·19.5 쪽으로 옮긴다.
4. 후진 팔 옆벽: x=±4.25, z −25.75…−19.95 구간을 아치(폭 4.5)로 뚫는다. 그 뒤(−30.25…−25.75)는 통벽 유지. 좌석 AL/AR(z −27.5…−19.9)의 바깥 끝 좌석(x ±3.6)과 아치 사이 0.65 m 는 그대로 둔다(통로는 아치 밖).
5. 새 바깥벽: x=±16.7 을 z −25.75…−13.25 와 −4.75…7.75 에, 끝벽을 z=7.75(x 10.95…16.7)와 z=−25.75(x 4.25…16.7)에. 재질은 기존 `surfBatch('limestone')` + `pilaster()`·`entablature(…, 7.2)`(측랑 높이 엔타블러처) + 걸레받이. 충돌체는 벽마다 AABB 1개.
6. 돔 피어의 새로 드러나는 면(x=±10.95 면과 z 면): `pilaster` 2개 + `niche` 1개씩(기념비 자리). 피어 충돌체는 그대로다.
7. 천장: 통로 2곳은 통형 궁륭(축 z, 시작 7.6, 상승 1.5 — 측랑과 같은 높이), 모서리 경당 4곳은 `ctx.dome({ r: 2.6, y: 9.0, rise: 2.4, lantern: {...} })` + 네 귀 펜던티브(색 면). 저화질에서는 분할을 절반으로.
8. 바닥: 기존 `texFloor` 로 x ±10.95…±16.7 띠 2장(z −25.75…7.75)을 추가하거나, 266~267행 바닥판의 x 범위를 넓힌다(메쉬 수가 덜 는다).
9. 제대(이름은 §1.1 표): 동쪽 모서리 경당은 바깥벽(x=±16.7) 가운데 z=4.85, 서쪽 모서리 경당은 서쪽 끝벽(z=−25.75) 가운데 x=±13.8. `ctx.altar({ style:'block', collide:true })` + 제단화 색 면. 배치는 근사(평면도의 번호 위치를 따름).
10. 경계·카메라: `bounds`(x ±25.5)와 `setCameraBounds` 는 그대로 충분하다. `yMax: 28` 유지.
11. 검증: `church_plan.mjs stpeter` 지도에서 (13.8, 4.8)→(13.8, −1.4)→(13.8, −9)→(13.8, −16.6)→(13.8, −22.8)→(7.6, −22.8)→(0, −22.8) 가 `.` 으로 이어져야 한다. 화면: `shot.mjs stpeter --pos 9,4.2 --yaw -90`(측랑에서 그레고리오 경당 쪽), `--pos 13.8,-9 --yaw 0`(익랑에서 통로), `--pos 0,-22 --yaw 90`(후진 팔에서 서쪽 경당).
12. 예산: 새 조형은 정점 2만 안팎(작은 돔 4개가 대부분). 고친 뒤 250k 를 넘으면 모서리 경당 돔의 `seg/rings` 를 줄인다.

**② 측랑 끝 제대 (P1, S)** — 돔 피어 동쪽 면(z=1.95), x=±8.97 중심: `niche(...)` 대신 제단화 틀(폭 2.4, 높이 4.2)+`ctx.altar({ x: ±8.97, z: 2.6, ry: 0, w: 2.2, style:'block' })`. 오른쪽(+x)은 제대 아래 유리관(성 요한 23세) 색 면. 충돌체 x ±7.8…±10.1, z 1.95…3.2.

**③ 세례 경당 (P1, S)** — 506행 `if (ci === 0)` 를 `if (ci === 0 && s > 0)`(피에타는 오른쪽만)로 바꾸고, `s < 0` 첫 경당에는 세례반: 붉은 반암 타원 수반(`ctx.cyl` r 0.9, h 0.7, 색 `0x7a2e2c`, `mat:'gloss'`) + 금동 덮개(원뿔 + 어린양 대신 작은 구).

**④ 성체 경당·성가대 경당 (P1, M)** — 아치 3번 칸(`zc = 12.85`)의 방만 깊이 2.9 → 6.0(x ±10.95…±16.95), 폭 3.8 → 7.5(z 9.1…16.6)로 키우고 입구 아치는 그대로 둔다(실제도 철창살 문으로 좁게 든다). 난간과 516행 충돌체를 걷어 내고 들어갈 수 있게 한다. 오른쪽(성체): 뒷벽 가운데 `ctx.tabernacle` + 금동 원형 신전 모양 감실(원기둥+작은 돔), 왼쪽(성가대): 양옆 벽에 목재 성가대석 2단(`mat:'wood'`). 촛불대(x ±8.9, z 17.2)의 `reach`·위치와 겹치지 않는지 본다(촛불대는 측랑 안쪽이라 겹치지 않는다). 이 방은 ①의 동쪽 모서리 경당(z ≤ 7.75)과 벽 하나(1.35 m)를 사이에 둔다.

**⑤ 성문·성인상 (P2, S)** — 문 x=+8.98 을 성문으로: 문짝을 16칸 부조 패널(4×4 작은 상자) + 문 위 십자가, 색은 밝은 청동 `0x6a5232`. 돔 피어 벽감 `niche(…kind)` 586행의 종류 배열을 방위별 이름표 주석과 함께 정리(론지노 = (+x, 동), 헬레나 = (+x, 서), 베로니카 = (−x, 서), 안드레아 = (−x, 동))하고 론지노는 창, 헬레나·안드레아는 큰 십자가(상자 2개), 베로니카는 흰 천(얇은 상자)을 든 실루엣으로.

**⑥ 측랑 천장 (P2, S~M)** — 472행 `bays: [1, 7]` 을 아치 칸 3곳(z 12.85, 21.5, 30.15)의 타원 돔 3개(`ctx.dome`, sx 1.0·sz 1.25 에 해당하는 타원은 `vault({type:'sail'})` 칸 길이 4.5 로 대신해도 된다) + 피어 뒤 통형 궁륭으로 바꾼다. 천창 유리(473~477행)는 돔마다 1개. 개구부 key 가 바뀌므로 `data/glass_windows/stpeter.json` 의 `aisle_skylight` 항목을 `church_openings.mjs stpeter --json` 결과로 갱신한다.

### 1.5 고치지 않기로 한 것 (stpeter)
- **현관(아트리움)**: 내부 길이만으로 68.95 m(상한 70 m)다. 넣으려면 scalePercent 를 33 으로 내려 모든 좌표를 다시 잡아야 한다. 내부 구조가 우선이다.
- **고정석이 없는데 의자를 둔 것·촛불대**: 앱 기능(앉기·초 봉헌)이다. 전례 때 실제로 의자를 놓는 자리(신랑 앞쪽, 의자의 제대 앞)에 두었으므로 유지한다.
- **콘페시오로 내려가는 계단·지하 동굴(그로테)**: 출입 불가 충돌체로 둔다.
- **경당 내부의 조각·기념비 세부, 피어 벽감 성인상 39점의 개별 구분**: SPEC 13절 방침(색 면·실루엣).
