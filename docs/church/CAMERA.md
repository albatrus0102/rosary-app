# 성당 3인칭 카메라 (2026-11-15 재설계)

이 카메라는 예측 가능하게 움직이고 내 캐릭터를 놓치지 않는 것을 목표로 한다. 구현은 `assets/church/cam_guard.js`(`createRig`·`classifyThin`·`patchSee`·`avatarAlpha`)와 `main.js updateCamera`, `avatar.js setXray`이다. 시험은 `tools/church_web/camera_rig.test.mjs`에 있다.

| 기법 | 출처 | 채택 / 이유 |
|---|---|---|
| 목표 거리 유지, 가림이 생기면 앞으로 당김(Pull Camera Forward) | Cinemachine Deoccluder, Unreal SpringArm `Target Arm Length`·`Do Collision Test` | **채택**: 넓은 벽·천장 앞에서만 당긴다. 그렇지 않으면 카메라가 실내 밖으로 나간다. |
| 당길 때와 놓을 때의 감쇠 차이, 최소 유지 시간(`Damping When Occluded` / `Damping` / `Smoothing Time`) | Cinemachine | **채택**: 당길 때는 0.25초, 벽 여유 0.6m 안에서 바로 당긴다. 놓을 때는 0.5초 버틴 뒤 0.8초(초당 최대 1.2m)에 걸쳐 돌아간다. 0.3m 히스테리시스를 둔다. |
| 프로브 반경(`Probe Size`) | Unreal SpringArm | **채택**: 벽에서 0.8m 앞에 서고, 좌우 ±0.3m 선 두 개를 더 쏜다. 벽 조각 틈으로 카메라가 새지 않게 한다. |
| 미리 보기(lookahead) | 3인칭 게임 관례 | **채택**: 0.6초 뒤의 위치와 방향을 미리 검사한다. 돌거나 들어갈 때 급히 당기지 않게 한다. |
| 다른 시점 찾기(Preserve Camera Distance / Height) | Cinemachine | **부분 채택**: 구석에 끼면 좌우 ±0.45~1.35rad 중 가장 먼 방향으로 비켜 선다. 뒤가 막히면 어깨 위(1.2rad)로 올라가 앞 1.6m를 본다. |
| `Transparent Layers`, 가림물 디더 | Cinemachine, 많은 3인칭 게임 | **채택**: 기둥·피어·성상(몸 높이에서 4.4m 이하로 떨어진 덩어리)은 카메라를 움직이지 않고 원뿔 안을 디더로 지운다. |
| 캐릭터 실루엣(X-ray) | 3인칭 게임 관례(가림 시 외곽선·실루엣) | **채택**: 가려진 몸을 금색 50% 디더로 그린다(GreaterDepth). 외곽선 셰이더는 비용 때문에 채택하지 않았다. |
| 근접 시 캐릭터 페이드 | 3인칭 게임 관례 | **채택(하한 있음)**: 1.7m부터 흐려지되 최소 불투명도 0.35를 지킨다. 캐릭터가 사라지지 않는다. |
| 걷는 방향으로 자동 재정렬(auto-recenter) | Cinemachine `Recentering` | **채택(설정)**: 앞쪽(±70°)으로 걸을 때만 아주 천천히 재정렬한다. 옆으로 걸을 때는 재정렬하지 않아 빙빙 돌지 않는다. |
| 카메라 지연(Camera Lag) | Unreal SpringArm | **유지**: 위치를 초당 7로 따라간다. |
| 발밑 위치 링 | 일부 MMO | **불채택**: 이름표와 X-ray로 충분하다. 바닥 장식과 겹친다. |

설정(설정 > 성당) 항목과 기본값은 다음과 같다.
- **카메라 거리**: 가까이 / 보통 / 멀리. 기본은 보통이다.
- **자동 줌(벽 피하기)**: 기본은 켬이다. 끄면 거리를 바꾸지 않고, 사이의 벽을 디더로 비춘다.
- **걸을 때 뒤로 따라가기**: 기본은 켬이다. 끄면 사용자가 돌린 방향을 그대로 둔다.

기도 자리의 '자리 시점'은 그대로 둔다. 도착할 때 한 번 부드럽게 옮기고, 화면을 끌면 바로 해제된다.
