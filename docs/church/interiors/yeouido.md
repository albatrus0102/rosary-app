# 여의도동성당 조사서 + 3D 설계서 (`yeouido`)

조사·구현일 2026-11-16. 로드맵 **T-79**(사용자의 본당). 당고개(`danggogae.md`)와 같은 방식으로 조사 → 설계 → 구현했다(§9 구현 결과).
사진은 저장소에 넣지 않았다. 본당 누리집 사진은 **눈으로 확인만** 했다(작업용 임시 폴더에서 열어 보고 지움. 텍스처·번들·문서 삽입 없음).

**표기 규칙**

| 표시 | 뜻 |
|---|---|
| **[확인]** | 서로 독립된 출처 2곳 이상에서 일치 |
| **[단일]** | 출처 1곳뿐(대부분 본당 누리집) |
| **[사진]** | 본당 누리집의 사진을 직접 열어 눈으로 읽은 것. 치수는 아님 |
| **[추정]** | 사진의 비례(신자석·사람 크기)에서 계산하거나 짐작한 값. 실측값이 아님 |
| **[미확인]** | 출처를 찾지 못함. 값이 있으면 모델링용 제안일 뿐 |

**가장 중요한 한계 세 가지**

1. **성전의 실측 치수·좌석 수·설계자(건축가)를 찾지 못했다.** 성전 폭·길이·높이는 모두 **[추정]** 이다. 검색 엔진(한국어 검색)과 위키백과·위키미디어 공용에서 성당 자료가 나오지 않았고, 본당 누리집에도 건축 자료는 없다.
2. **성전 바닥 평면(긴 홀인지, 팔각에 가까운지)은 사진 몇 장에서 짐작했다.** 바깥에서 보이는 초록 지붕은 여러 면으로 된 팔각형에 가까운 모임지붕이고, 안에서 찍은 사진은 모두 '중앙 통로 → 반원 후진' 축으로 찍혀 있다 → 축이 긴 직사각 홀 + 반원 후진 + 천장 가운데 팔각 오목으로 지었다(§6).
3. **성당 안의 유리화·부활하신 그리스도 상·감실 부조·독서대 조각·파티마 성모상은 작가가 확인되지 않은 현대 작품이다.** 저작권이 살아 있다고 보고 복제·모사하지 않는다(§4).

**알아 둘 사실(facts)**

1. 1974년 9월 17일 영등포 본당의 여의도 공소에서 본당으로 승격했습니다.
2. 지금의 성전은 1982년에 공사를 시작해 1984년 4월 28일 봉헌되었고, 2008년부터 2009년까지 증축과 보수를 거쳤습니다.
3. 본당 주보는 1983년에 '파티마의 성모'로 정해졌고, 1986년 8월 15일 성모동산을 꾸며 성모상을 축복했습니다.
4. 1984년 5월 6일 요한 바오로 2세 교황이 한국 순교자 103위를 시성한 여의도 광장(지금의 여의도공원)이 가까이 있어, 본당은 그 시성 터를 순례지로 안내합니다.

### 4.1 무엇이 누구의 것인가

- 걷기 시험(`yeouido.test.mjs`): 입구 → 제대 앞·성모상 앞·제단 양옆·뒤 구석을 누르기 이동으로 끝까지 걸어가고 그 길이 제단 금지 구역을 지나지 않음, 왼쪽 ↔ 오른쪽 옆 통로를 앞·뒤로 건넘, 뒷벽·후진 바깥·제대·감실·독서대·성수대는 막힘.
