# florence — 피렌체 대성당 (Santa Maria del Fiore) 내부 조사서

> 내부 모델링용 사실 자료. 수치는 출처와 신뢰도(상/중/하)를 붙였고, 확인하지 못한 것은 **미확인**으로 적었다.
> 사진은 사용·묘사하지 않았다. 평면 관계(베이 길이, 팔각 크기, 성가대·제대 위치)는 1733년 스그릴리(Sgrilli) 실측 평면 판화(브라초 축척 포함, 공용 도메인)에서 재어 문헌 수치와 맞추었다.
> 주의: 과제 설명에는 "3칸 신랑"이라고 되어 있으나 실제 신랑은 **4칸**이다(en.wikipedia "four square bays", 평면도 일치).

## 1. 개요

| 항목 | 내용 |
|---|---|
| 한국어 이름 | 피렌체 대성당 (산타 마리아 델 피오레, 꽃의 성모 대성당) |
| 원어 이름 | Cattedrale di Santa Maria del Fiore (Duomo di Firenze) |
| 위치 | 이탈리아 토스카나주 피렌체, 두오모 광장 |
| 종류 | 대성당(피렌체 대교구 주교좌). 카탈로그 종류 값: `대성당` |
| 착공 | 1296년 9월 8일(it) / 9일(en·ko) — 출처 간 하루 차이 |
| 축성 | 1436년 3월 25일, 교황 에우제니오 4세 |
| 완공 | 본체·돔 1436년, 꼭대기 탑(란테르나) 1461년, 금동 구 1468–1469년경, 정면 1887년 |
| 주요 건축가 | 아르놀포 디 캄비오(원안), 조토·안드레아 피사노(종탑), 프란체스코 탈렌티·조반니 디 라포 기니(신랑부), 필리포 브루넬레스키(돔), 미켈로초(란테르나 마무리), 에밀리오 데 파브리스(정면) |
| 카탈로그 건립 연도 표기 제안 | `1296–1436` |

**앱 카드용 설명(2문장)**
> 1296년에 착공해 1436년에 축성된 피렌체 대교구의 주교좌 성당으로, 브루넬레스키가 올린 팔각 돔은 지금도 벽돌로 쌓은 돔 가운데 세계에서 가장 큽니다. 내부는 장식이 적고 넓게 트여 있으며, 돔 안쪽 전체에 바사리와 추카리가 그린 '최후의 심판' 프레스코가 펼쳐져 있습니다.

**알아 둘 사실 3가지**
1. 돔 안쪽 프레스코 '최후의 심판'(1572–1579, 바사리·추카리)은 약 3,600㎡로, 여덟 면과 여섯 단의 띠로 나뉜다.
2. 입구 위 안쪽 벽에는 파올로 우첼로가 1443년에 그린 큰 시계가 있다. 바늘이 하나이고 해 질 때를 24시로 삼는 '이탈리아식 시간'을 가리킨다.
3. 신랑과 익랑·제단부가 따로 없이, 돔 아래 팔각 공간에서 같은 모양의 다각형 '트리부나' 세 개가 세 방향으로 뻗어 평면이 세잎 모양이다. 트리부나마다 경당이 5개씩 있다.

## 3. 평면과 공간 구성 (입구 → 제대)

1. **정면 안쪽 벽**: 문 3개. 중앙문 위 반월창에 '성모 대관' 모자이크(가도 가디), 그 위에 우첼로의 시계(네 모서리에 얼굴 넷), 그 위 둥근 스테인드글라스 창(성모 승천, 기베르티 도안). 좌우 측랑 끝에도 둥근 창.
2. **신랑 4칸**: 중앙 신랑(약 19.8m)과 좌우 측랑. 칸이 매우 커서(약 19.7m) 기둥이 3쌍뿐이고, 넓은 첨두 아치가 기둥 사이를 잇는다. 벽은 흰 회벽, 기둥·아치·리브는 갈색 돌이라 선이 뚜렷하다. 장식이 적어 텅 빈 느낌이 강하다.
3. **발코니(발라토이오)**: 아케이드 위, 궁륭 기점 높이에서 까치발 위 통로가 신랑과 팔각 공간 둘레 전체를 한 줄로 돈다. 내부에서 가장 눈에 띄는 가로선이다.
4. **고창**: 칸마다 좌우 둥근 창 1개씩(신랑 합계 8개). 측랑 벽에는 높은 이련창(비포라).
5. **측랑 벽의 그림**: 왼쪽(북) 벽에 기마상 프레스코 2점 — 존 호크우드(우첼로, 1436, 녹색 단색)와 니콜로 다 톨렌티노(카스타뇨, 1456, 대리석 색) — 과 '단테와 신곡'(1465).
6. **옆문**: 좌우 벽에 2개씩(종탑 문·참사회원 문은 남쪽, 발라 문·만도를라 문은 북쪽).
7. **대리석 바닥**: 전체가 다색 대리석 기하 무늬(1520–1560, 바초 다뇰로 등). 칸마다 큰 원·사각·별 무늬가 다르다.
8. **팔각 공간(돔 아래)**: 면 간 약 42m. 서쪽 면은 신랑으로, 동·남·북 면은 트리부나로 열려 있고, 대각 네 면은 거대한 벽기둥이다. 대각 벽기둥의 감실에 사도상 8개. 동쪽 두 대각 벽에는 성구실 문(위에 1842년 네오고딕 아치와 오르간·성가대 발코니), 서쪽 두 대각 면은 측랑 끝과 이어진다.
9. **성가대 울타리와 주제대**: 돔 한가운데 팔각 대리석 낮은 울타리(반디넬리, 1547–1572; 현재는 부조가 있는 받침부만 남음). 안쪽 동편에 몇 단 높은 제대 구역, 중앙에 주제대(1973년 배치), 뒤에 15세기 나무 주교좌와 등받이 벽, 그 위에 채색 나무 십자고상(베네데토 다 마이아노, 1495년경).
10. **돔**: 드럼에 둥근 창 8개(성모 생애 스테인드글라스; 신랑에서 보이는 것은 동쪽의 '성모 대관' 하나). 그 위 8면 첨두 돔 안쪽 전체가 '최후의 심판'. 꼭대기 가짜 란테르나 둘레에 묵시록의 원로 24명, 아래로 천사 합창, 성인 무리, 덕·은사, 가장 아래 띠에 지옥과 죄. 신랑 맞은편 동쪽 면에는 영광의 그리스도와 성모·세례자 요한.
11. **트리부나 3개**: 동(성 자노비), 남(무염시태), 북(성 십자가). 각각 다각형 공간에 방사형 경당 5개, 경당마다 높은 이련창. 동쪽 가운데 경당에 성 자노비의 청동 유해함(기베르티). 북쪽 트리부나 바닥에 토스카넬리의 해시계 선.
12. **지하**: 신랑 아래 산타 레파라타 옛 성당 유적(브루넬레스키 무덤). 모델에서는 생략.

## 7. 좌석·기도 위치 제안

고정 신자석은 없고 전례 때 의자를 신랑 앞쪽과 돔 아래에 놓는다. 그에 맞춘 안으로 합계 90석. 줄 간격 1.9m(통로 1.4m 이상).

```json
{
  "id": "florence",
  "scalePercent": 45,
  "bounds": { "x0": -20.2, "x1": 20.2, "z0": -33.5, "z1": 33.5 },
  "spawn": { "x": 0, "z": 31.3, "r": 0 },
  "seatGroups": [
    { "g": "NL", "rows": 12, "perRow": 3, "origin": { "x": -1.3, "z": 0.0 }, "dx": -1.0, "dz": 1.9, "rowDx": 0, "yaw": 0 },
    { "g": "NR", "rows": 12, "perRow": 3, "origin": { "x": 1.3, "z": 0.0 }, "dx": 1.0, "dz": 1.9, "rowDx": 0, "yaw": 0 },
    { "g": "OL", "rows": 3, "perRow": 3, "origin": { "x": -6.2, "z": -13.0 }, "dx": -1.0, "dz": 1.9, "rowDx": 0, "yaw": 0 },
    { "g": "OR", "rows": 3, "perRow": 3, "origin": { "x": 6.2, "z": -13.0 }, "dx": 1.0, "dz": 1.9, "rowDx": 0, "yaw": 0 }
  ],
  "candles": {
    "stands": [
      { "x": -7.7, "z": 11.5, "slots": 20, "reach": 1.8 },
      { "x": 7.7, "z": 11.5, "slots": 20, "reach": 1.8 }
    ]
  }
}
```

- NL/NR: 중앙 신랑, z 0.0 ~ +20.9, x ±1.3 ~ ±3.3 (중앙 통로 2.6m). 72석. 기둥(±4.46) 표면과 0.5m 이상 떨어짐.
- OL/OR: 팔각 공간 안, 성가대 울타리(x ±4.95)와 팔각 벽(x ±9.45) 사이. z −13.0 ~ −9.2. 18석. 모든 좌석이 팔각 안쪽(|x| + |z + 12.93| ≤ 13.36)에 있다.
- 촛불대: 측랑 벽 앞, 둘째·셋째 기둥 사이 칸 가운데. 실제 봉헌초 위치는 **미확인**.
- `bounds`는 전체를 감싸는 직사각형이다. 세잎 평면 바깥(신랑 옆 빈 모서리, 성구실, 트리부나 사이)과 성가대 울타리·제대 단은 빌더 충돌체로 막아야 한다.

## 8. 조명·시간대 메모

- **빛이 드는 길**: 신랑 둥근 고창 8개, 정면 둥근 창 3개, 측랑 이련창 몇 개, 드럼 둥근 창 8개, 란테르나, 트리부나 경당 창. 유리가 짙어 들어오는 빛이 적다.
- **정오**: 돔 아래가 가장 밝고 프레스코 위쪽 금빛·하늘색 띠가 보인다. 신랑은 흰 벽의 반사광으로 고르고 부드럽다. 남쪽(+x) 고창에서 둥근 빛 무늬가 북쪽 벽과 바닥에 떨어진다. 하지 무렵 정오에는 북쪽 트리부나 바닥 자오선에 햇빛 원이 놓인다.
- **해 질 녘**: 서쪽 정면의 둥근 창으로 낮은 주황빛이 신랑 축을 따라 들어와 팔각 공간 쪽 벽기둥에 닿는다. 돔은 아래부터 어두워진다.
- **밤(촛불)**: 창은 어두운 면. 갈색 기둥 아래쪽과 제대 구역만 따뜻하게 밝고, 흰 벽은 회갈색으로 가라앉으며 돔 안은 거의 보이지 않는다. 제대 뒤 십자고상에 약한 조명을 두면 초점이 생긴다.
