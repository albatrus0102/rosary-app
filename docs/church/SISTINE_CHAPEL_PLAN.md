# 시스티나 성당 추가 계획 (보류 — 2026-11-13 사용자가 "나중에 하자"로 결정)

## 요약
- 가능 여부: **가능**. 구조가 단순하다(긴 직사각형 홀 + 둥근 궁륭 천장 + 제대 벽 최후의 심판 + 대리석 칸막이·성가대석 + 벽 쪽 긴 나무 의자).
- 핵심은 모델이 아니라 **그림**이다: 천장화(미켈란젤로)와 최후의 심판 벽, 측면 벽 아랫단 장식 그림 띠.
- 기존 성당 하나를 추가하는 작업량과 비슷하다(성당 빌더 `ch_sistine.js`, 성당 목록 등록, 십자가의 길 판 자리, 서버 레이아웃 내보내기, 테스트, 스크린샷).

## 기존 기능 재사용
- 올려다보기 카메라(look-up), 사진 창 그리기 방식(알파 윤곽·색 보정 없는 경로), 성당 선택 목록·접속 인원, 14처 판 자동 배치(`way_cross.js`).

## 한계와 위험
1. **해상도·용량**: 천장 약 13×40m. APK 20MB대 목표(현재 약 26MB)를 지키려면 천장화+최후의 심판을 합쳐 약 1.5MB, 2k 수준 한두 장으로만 가능 → 가까이서 보면 흐림. 서버가 생기면 고해상도를 근접 시에 받는 방식 권장.
2. **그림 사진의 권리**: 작품 자체는 퍼블릭 도메인이지만 사진은 바티칸 박물관이 촬영·사용에 제한을 둔다. 위키미디어 공용의 'PD-Art' 표시 파일이 있으나 이탈리아 문화유산법·박물관 정책 때문에 상업·대규모 배포에서 분쟁 소지가 있다. **출시 전 법률 검토 필수**(스테인드글라스의 '이탈리아 문화유산법 검토' 항목과 같은 종류, docs/church/ASSET_LICENSES.md 참고).
3. **일반 성당과 성격이 다름**: 본당 신자석이 있는 성당이 아니라 특별 예식 경당. 앉아서 기도·무릎 꿇기 구조 없음 → 벽 쪽 긴 의자만 두는 단순화, '기도 공간 + 관람 공간' 정리 필요.
4. **스테인드글라스 컨셉과 거리**: 색유리 창이 사실상 없다 → 순수 성화 감상 성당이 된다.

## 진행하려면 정할 것
1. 그림 사진 확보: 위키미디어 PD-Art 로 시작하고 이 성당만 '시안' 표시 + 출시 전 법률 검토 체크리스트에 넣을지, 권리가 확실해질 때까지 보류할지.
2. 용량: 약 1.5MB 증가 허용 여부(APK 약 26MB → 27~28MB).
3. 시작 시점(성당 메인 개편 직후 등).

## 시작 방법
사용자가 "시스티나 진행"이라고 말하면 위 세 가지 결정을 받고 시작한다.
