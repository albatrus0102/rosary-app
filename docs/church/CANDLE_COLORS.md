# 봉헌초 색 (CANDLE_COLORS)

## 출처 메모 (2026-11-16, 사용자가 ChatGPT로 조사한 내용 — 1차 자료 아님)
- 우리나라 성당·성지에서 판매가 확인된 색: 빨강, 파랑, 초록, 노랑, 흰색/투명.
- 외국에서 보이는 색: 분홍, 보라, 호박색(amber).
- 색마다 기도 지향을 정해 둔 공식 가톨릭 규정은 없다.
- 흔한 상품 형태: 색유리 컵 안에 상아색/흰 초.
- 따라서 앱은 색에 뜻이나 효능을 붙이지 않는다. 시트 안내문: "봉헌초의 색은 자유롭게 고르세요. 촛불의 색보다 하느님께 봉헌하는 기도와 마음이 중요합니다."

## 색 번호(서버 `color`, 저장 `c:<slot>`, Dart `candleColors`, 장면 `CANDLE_COLORS`)
번호는 저장된 옛 초와 호환되도록 고정한다. 0..5는 바꾸지 않고, 새 색은 뒤에 덧붙인다.

| 번호 | 이름(접근성 라벨) | 유리색 |
|---|---|---|
| 0 | 흰색 (흰/투명) | 0xe4ecee |
| 1 | 빨강 (루비) | 0xc01c34 |
| 2 | 노랑 (황금) | 0xf2b929 |
| 3 | 파랑 (코발트) | 0x2c62d2 |
| 4 | 초록 (에메랄드) | 0x1f9d5c |
| 5 | 분홍 (로즈) | 0xea7aa2 |
| 6 | 보라 | 0x8b5bd4 |
| 7 | 호박색 | 0xe58a1f |

시트 표시 순서(`candleColorUiOrder`): 흰색, 빨강, 파랑, 초록, 노랑(확인된 5색) → 분홍, 보라, 호박색.
서버 검증 범위 0..7(`CANDLE_COLOR_MAX`), 색 없는 옛 초는 그대로 허용.

## 장면(assets/church/world.js)
- 색은 반투명 유리 컵을 물들인다. 촛농은 항상 상아색.
- 켠 초: 컵이 안쪽 불꽃으로 은은히 빛난다(인스턴스 속성 `aGlow`, draw call +0).
- 다 탄 칸: 유리색은 남기되 어둡고 안쪽 빛 없음.
