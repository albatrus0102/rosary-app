# 아바타 외형 기준 (코드 아바타, `assets/church/avatar.js`)

코드로 만든(절차 생성) 아바타의 **외형 품질·스타일 통일 기준**이다. 사실적 3D 캐릭터(GLB, `avatar_glb.js`)로의 교체는
뒤로 미뤘고, 이 문서는 그때까지 쓰는 코드 아바타만 다룬다. 와이어·저장 형식(`skin, style, hair, outfit, name, g, nv`)과
옵션 개수(피부 4, 머리 모양 4×성별 2, 머리색 10, 옷색 12)는 **바뀌지 않았다**. 미사보(채플 베일) 옵션은 넣지 않았다.

- 구현: `assets/church/avatar.js`, 색: `assets/church/palette.js`(Flutter `lib/church/avatar/avatar_config.dart` 와 같은 값)
- 2D 미리보기(편집 화면·첫 설정): `lib/church/avatar/avatar_preview.dart`
- 시험: `tools/church_web/avatar.test.mjs`(예산·비침투·LOD 실루엣), `test/church_avatar_*_test.dart`
- 스크린샷 하니스: `test/zz_avatar_look_shots_test.dart`(`--dart-define=AVATAR_LOOK_SHOTS=<dir>`)

## 1. 진단 — 참고 앱(가상 성당 '평화의 대성당')과의 격차

참고 화면의 아바타는 "원뿔형 몸통 + 큰 머리 + 절제된 한 벌의 색"이다. 모양을 베끼지 않고, 격차만 항목별로 적는다.

| 항목 | 고치기 전(우리) | 참고 앱 | 조치 |
|---|---|---|---|
| 실루엣 비율 | 7.7등신의 길고 가는 성인 체형, 어깨가 각지고 팔다리가 막대 같음 | 2.5~3등신, 한 덩어리 원뿔 | 머리 1.55배(약 5등신), 여성은 종 모양 원피스로 하체를 한 덩어리로, 어깨 소매 윗단을 낮춰 둥글게 |
| 머리-몸 비율 | 머리 폭 16cm(어깨의 46%) — 멀리서 얼굴이 점으로 보임 | 머리가 몸보다 큼 | 머리 폭 24cm(어깨의 73%), 원거리 임포스터도 같은 배율 |
| 팔·손 | 가는 팔, 작은 벙어리장갑 | 팔 없음(몸통에 붙음) | 팔 6% 굵게, 손 1.14배(손목 기준) |
| 얼굴 | 큰 타원 눈, 굵은 눈썹, 큰 코, 넓은 미소 — 사실 비율이라 어색 | 작은 점 눈, 볼 | 눈을 작게·낮게·넓게 + 반짝임, 눈썹 가늘게, 코·미소 최소, 볼 홍조 |
| 머리카락 | 단색 덩어리(재질감 없음), 얇은 껍질 | 단색 덩어리(큰 볼륨) | 머리와 함께 1.55배(두께·볼륨 증가), 윤기 띠(정수리 아래 밝은 고리)와 가르마 선을 정점 색으로 |
| 옷 | 후디(뒤 후드·캥거루 주머니·굵은 리브) — 성당과 어울리지 않고 거칠다 | 단색 + 금색 밑단 | 단색 웃옷 + 가는 트림(깃·소맷부리 크림, 아랫단 금색), 남성 단추 3개 |
| 재질 | roughness 0.74/0.82, 림 없음 — 벽·바닥과 같은 질감 | 매끈한 토이, 약한 림 | roughness 0.66/0.78, 약한 Fresnel 림 라이트(따뜻한 흰색) |
| 장면과의 분리 | 어두운 옷이 어두운 의자·벽에 묻힘 | 윤곽이 밝게 떠 있음 | 림 라이트(옷 0.26, 피부·머리 0.20, 원거리 0.22) |
| 그림자 | 발밑 둥근 얼룩(유지) | 없음 | 유지(크기 그대로; 접지감은 장면 그림자가 담당) |
| 이름표 | 정수리 바로 위 | 없음 | 머리가 커진 만큼(+0.128m) 올림. 크기·겹침 규칙(`label_fit.js`)은 그대로 |
| 색 채도 | 원색에 가까운 옷(#2F4A8A, #D9694B…), 옷색을 섞은 분홍·하늘색 신발 | 낮은 채도의 통일된 색 | 12색을 같은 색상에서 채도만 낮춤, 신발은 짙은 중성색 |
| 군중 통일감 | 사람마다 색이 튀고 실루엣이 가늘어 산만 | 같은 실루엣의 반복 | 같은 트림·같은 실루엣(성별 2종), LOD1·2도 같은 비율 |

## 2. 형태

- **머리**: 머리·얼굴·머리카락을 원래 크기로 만든 뒤 목 위(`HEAD_PIV = 1.468`)를 중심으로 `HEAD_S = 1.55`배 키운다.
  뼈대·자세·좌석 정합은 그대로다. 정수리가 `HEAD_UP = 0.128m` 높아져 이름표 기준 높이도 그만큼 올렸다.
  턱선은 덜 깎아 볼이 통통한 둥근 얼굴(성별 차이는 줄였다).
- **얼굴**: 눈 = 작은 짙은 점(낮고 넓게: `EYE_X 0.0345, EYE_Y -0.008`) + 흰 반짝임, 눈썹 = 가는 알약,
  코 = 아주 작은 혹, 입 = 폭 2.7cm 의 가는 미소, 볼 = 분홍 홍조(정점 색). 중간 LOD 는 눈·눈썹·코만.
- **머리카락**: 모양 8종(성별 × 4)의 뜻은 그대로. 윤기 띠와 가르마 선(여성 어깨 길이·낮은 쪽머리, 남성 가르마)을
  정점 색으로 넣는다(텍스처 없음).
- **옷**: 여성은 무릎 바로 위(`HEM[0] = 0.52`)까지 내려오는 종 모양 원피스(허리가 들어가고 아랫단으로 퍼짐) + 가는 다리.
  남성은 엉덩이를 덮는(`HEM[1] = 0.76`) 단정한 웃옷 + 일자 바지. 깃·소맷부리는 크림색 가는 띠, 아랫단은 금색 가는 띠,
  남성 웃옷 앞에 작은 단추 3개. 후드·주머니·굵은 리브는 없앴다.
- **원피스의 움직임**: 앞자락은 허벅지를 따라가고(`ckL/ckR` 뼈), 뒷자락은 `skirt` 뼈에 붙어 앉으면 좌석판 위로 접힌다
  (`SKIRT_SIT = 0.17`). 앉으면 앞자락이 허벅지 위에 내려앉고(`LAP_FLAT = 0.78`), 무릎 꿇으면 조금 뒤로 당긴다(`KNEEL_HEM = 0.10rad`).

인덱스·개수·이름(뜻)은 그대로이고 HEX 만 조화로운 한 벌로 바꿨다(성당의 돌·나무·금색과 어울리는 따뜻한 중간 채도).

| 머리 10 | `#2E2826 #4B352B #6A4734 #85573B #9C5D40 #B8945E #D9BF86 #9C9A9B #DEDBD3 #7E3D37` |
| 옷 12 | `#455A8C #60646E #3C3C44 #C29B68 #7F8A58 #964C5A #4D7C68 #EFE6D1 #A39385 #7F9DBB #866389 #BF725C` |

## 4. 재질·빛

- `MeshStandardMaterial` 3개(피부·머리 / 옷 / 원거리)를 모든 아바타가 공유한다(정점 색으로 틴트). metalness 0.
- 림 라이트: `onBeforeCompile` 로 조각 셰이더에 Fresnel 항 한 줄(`pow(1 - N·V, 2.6)`)을 더한다. 텍스처·조명·패스 추가 없음.
  색은 따뜻한 흰색(1.0, 0.93, 0.82), 세기는 `RIM`(옷 0.26, 피부·머리 0.20, 원거리 0.22).

## 5. 성능·LOD

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 근접(LOD0) 삼각형 | 4,984 ~ 5,356 | 4,940 ~ 5,192 (−0.9 ~ −4.4%) |
| 중간(LOD1) 삼각형 | 1,284 ~ 1,380 | 1,240 ~ 1,324 (−1.8 ~ −6.6%) |
| 원거리(LOD2) 삼각형 | 376 / 382 / 382 | 여성 336 / 342 / 342, 남성 356 / 362 / 362 |
| draw call(사람당) | LOD0·1: 2(+그림자 1, 이름표 1, 묵주 1), LOD2: 1 | 같음 |
| 재질 | 3개 공유 | 3개 공유(셰이더 프로그램도 3개) |
| 텍스처 | 그림자 1 + 이름표 | 같음(추가 없음) |

- LOD1 은 같은 비율의 단순 메시, LOD2 임포스터는 성별별(여성 원피스 / 남성 웃옷+바지) × 자세 3종 = 6개 지오메트리를 공유한다.
- 예산(시험): 근접 ≤ 6,000, 중간 ≤ 1,500, 원거리 ≤ 400.

## 6. 좌석·무릎틀과의 비침투

뼈 길이·관절 위치·`SEAT_BACK`·`kneelSpot`·`KNEEL_*` 상수는 **바꾸지 않았다**(다시 보정할 필요가 없었다). 바뀐 것은 옷·머리의
겉모양뿐이라, 뼈 위치가 아니라 **실제 스키닝된 정점**으로 확인하는 시험을 더했다(`avatar.test.mjs` 의 `look:` 시험 4개).

- 앉기(기도 포함): 웃옷·원피스 자락이 좌석판 윗면 아래로 내려가지 않는다(허벅지 밑면이 눌리는 4.5cm 까지 허용: 예전과 같음),
  등받이 앞면보다 앞, 앞줄 등받이 뒷면·책 선반·무릎틀에 닿지 않는다, 옆으로 0.34m(좌석 간격 1.0m 의 1/3) 안.
- 무릎 꿇기: 원피스 아랫단·배·큰 머리가 앞줄 등받이 뒷면과 책 선반을 넘지 않는다(등받이 윗단 6cm 는 얹은 팔), 무릎은 무릎틀 위.
- 성호: 이마 목표를 큰 머리 앞면 밖으로 옮겼다(가슴 로컬 `[0.02, 0.43, -0.215]`). 인사: 손목 목표를 바깥으로 5cm.
- 묵주: 쥔 곳을 손 크기에 맞춰 `ROSARY.PALM 0.062`.

## 7. 남은 격차(냉정한 평가)

전/후 비교(같은 장면 코드·같은 시점, 360x800)를 눈으로 본 결론: **'정돈된 한 벌의 토이 캐릭터'로 올라섰고 군중이 한 가족처럼 보인다.**
참고 앱과 견주면 색·트림·얼굴의 완성도는 같은 급에 가깝지만, 아래는 아직 남아 있다.

1. **등신**: 뼈 길이(좌석·무릎틀 정합의 기준)를 그대로 두어 약 5등신이다. 참고 앱의 2.5~3등신 '원뿔 인형'만큼 상징적이지는 않다.
   다리·팔이 여전히 길다. 더 줄이려면 뼈대와 좌석 정합 상수(`SEAT_BACK`, `kneelPose`, 손 목표)를 함께 다시 잡아야 한다.
2. **손**: 벙어리장갑 + 엄지 혹 그대로다(가까이서 보면 엄지가 붙인 조각처럼 보인다).
3. **앉은 원피스 자락**: 열 수(18)가 적어 무릎 위 자락의 옆 모서리가 조금 각져 보인다. 중간 LOD 에서는 더 단순하다.
4. **옷 주름·질감**: 정점 색 단색이라 주름·직물 결이 없다(텍스처를 쓰지 않는 방침의 한계).
5. **머리카락**: 윤기 띠·가르마는 정점 밀도만큼만 선명하다. 올 단위 표현은 없다.
6. **미사보·전례 소품**: 넣지 않았다(사용자 결정). 넣는다면 `style` 범위 확장 = 와이어·서버 검증 변경이 필요하다.
7. **사실적 3D 캐릭터**: GLB 교체(`avatar_glb.js`)는 뒤로 미룬 상태 그대로다.

## 8. 인수인계 (작업 중단 시점 정리)

**끝난 것(안정 상태, 모두 시험 통과)**
- 큰 머리·호감형 얼굴·머리 윤기/가르마·단색 옷 + 트림·여성 종 모양 원피스·남성 단추·채도 낮춘 팔레트·림 라이트(`avatar.js`, `palette.js`).
- LOD1 메시와 LOD2 임포스터(성별별)를 같은 실루엣으로, 삼각형은 전 단계에서 줄었고 draw call·재질·텍스처 수는 그대로.
- 2D 미리보기(`avatar_preview.dart`)와 Flutter 색(`avatar_config.dart`)을 같은 외형·같은 HEX 로 맞춤. 편집 화면·첫 설정은 글자 2배에서도 겹침 없음.
- 실제 스키닝 정점으로 보는 비침투·LOD 실루엣 시험 4개(`avatar.test.mjs` 의 `look:`), 스크린샷 하니스(`test/zz_avatar_look_shots_test.dart`).
- 와이어·저장 형식, 서버 검증, 옵션 개수는 건드리지 않았다(미사보 제외).

**남은 것**: 위 7절의 1~5(등신, 손, 앉은 자락 모서리, 옷 질감, 머리카락 결).

**다음에 먼저 할 3가지**
1. 손 다듬기: 엄지 혹을 손바닥 loft 에 합치거나 더 납작하게(가까이서 가장 눈에 띄는 흠).
2. 앉은 원피스 자락: 근접 메시의 아랫자락 열 수를 늘리거나(18 → 24) 옆 자락을 아래로 늘어뜨려 모서리를 둥글게. 그 뒤 `look:` 시험과 앉기·무릎 스크린샷 재확인.
3. 실제 기기(저사양 포함)에서 림 라이트 세기(`RIM`)와 어두운 성당(밀라노·성 베드로)에서의 옷 밝기를 확인하고 필요하면 `RIM`·팔레트 미세 조정.

**주의**
- `HEAD_S`·`HEM`·`SKIRT_SIT`·`LAP_FLAT`·`KNEEL_HEM` 을 바꾸면 반드시 `node --test tools/church_web/avatar.test.mjs` 의 `look:` 시험과 앉기/무릎 꿇기 스크린샷을 다시 본다.
- 팔레트 HEX 는 `palette.js` 와 `avatar_config.dart` 두 곳이 같아야 한다(트림 색은 `avatar_preview.dart` 의 `_trimCream/_trimGold` 도).
- 머리 배율은 `avatar_preview.dart` 의 `_headScale/_headPivot` 과 `avatar.js` 의 `HEAD_S/HEAD_PIV` 가 같아야 한다.
- 스튜디오(장면 없이 MSAA 로 찍은 화면)에서 옷 앞면에 보이는 점선은 swiftshader 의 MSAA 흔적이다. 실제 장면 파이프라인에서는 나타나지 않는다.
- 전/후 스크린샷은 다른 작업(조명·재질·장식)이 장면 파일을 고치는 중에 찍으면 검게 나올 수 있다. 장면 파일을 고정한 사본에서 아바타 파일만 바꿔 찍는다.
