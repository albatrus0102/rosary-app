# 전례 시기별 성당 장식 (C-07 / G-41)

성당 3D 장면은 **오늘의 전례 시기**에 맞춰 제대 앞 보의 색과 시기 장식을 스스로 바꾼다.
규칙은 `lib/domain/liturgical_season.dart`(달력)와 `assets/church/liturgy.js`(장식) 두 곳에 있다.
와이어 규격은 `SPEC.md` §33.

## 1. 전례 달력 규칙

기준은 **로마 보편 전례력**이고, 날짜 경계는 **한국 표준시(KST) 자정**이다.

| 시기 | 기간 | 기본 색 | 이름(칩 부제) |
|---|---|---|---|
| 대림 | 대림 제1주일(11/27~12/3 사이 주일) ~ 12월 24일 | 자색 | 대림 시기 |
| 성탄 | 12월 25일 ~ 주님 세례 축일(1월 6일 다음 주일, 1/7~1/13) | 백색 | 성탄 시기 |
| 연중(전반) | 주님 세례 다음 날 ~ 재의 수요일 전날 | 녹색 | 연중 시기 |
| 사순 | 재의 수요일(부활 46일 전) ~ 성주간 수요일 | 자색 | 사순 시기 |
| 파스카 성삼일 | 성목요일 ~ 성토요일 | 목: 백색, 금: 홍색, 토: 자색 | 파스카 성삼일 |
| 부활 | 주님 부활 대축일 ~ 성령 강림 대축일(부활 후 50일째) | 백색 | 부활 시기 |
| 연중(후반) | 성령 강림 다음 날 ~ 대림 제1주일 전날 | 녹색 | 연중 시기 |

색 예외:

- **장미색**: 대림 제3주일(기뻐하여라), 사순 제4주일(즐거워하여라). 그 주일 하루만.
- **홍색**: 주님 수난 성지 주일, 성금요일, 성령 강림 대축일, 한국 순교 성인 대축일(9월 20일).
- **백색**(연중 시기 안의 대축일): 삼위일체(부활+56일), 성체 성혈(부활+60일), 예수 성심(부활+68일), 성모 승천(8월 15일), 모든 성인(11월 1일), 그리스도 왕(대림 제1주일 한 주 전), 원죄 없이 잉태되신 성모(12월 8일, 주일이면 9일).
- **자색**: 재의 수요일, 위령의 날(11월 2일).

표시하는 대축일·축일(21개): 천주의 성모 마리아(1/1), 주님 공현(1/6), 주님 세례, 재의 수요일, 성지 주일, 성목·성금·성토요일, 주님 부활, 주님 승천(부활+39일), 성령 강림, 삼위일체, 성체 성혈, 예수 성심, 성모 승천, 한국 순교 성인, 모든 성인, 위령의 날, 그리스도 왕, 원죄 없이 잉태되신 성모, 주님 성탄.

**성월(한국 교회 신심의 달)**: 3월 성 요셉, 5월 성모, 6월 예수 성심, 9월 순교자, 10월 묵주 기도, 11월 위령 성월.
전례 시기와 별개의 값이고, 칩 부제에는 연중 시기일 때만 `연중 시기 · 위령 성월`처럼 덧붙인다.

### 가정(정해 둔 것)

1. **이동 대축일은 로마 기준.** 한국 교회는 주님 공현을 1월 2~8일 사이 주일, 주님 승천을 부활 제7주일, 성체 성혈을 삼위일체 다음 주일에 지내지만, 여기서는 1월 6일·부활 후 40일째 목요일·삼위일체 다음 목요일로 둔다(색은 어느 쪽이든 백색이라 장식은 같다. 칩에 축일 이름이 뜨는 날짜만 며칠 다르다).
2. **위령 성월(11월)은 자색 기조로 꾸민다.** 11월의 연중 평일·주일 전례 색은 녹색이지만, 한국 교회 관행(위령 성월의 추모 분위기)에 따라 **성당 장식**은 자색 제대보 + 추모 촛불로 한다. 달력 값 `color`는 녹색 그대로이고 장식 값 `decorColor`만 자색이다. 모든 성인(11/1)·그리스도 왕의 백색은 그대로 두고 추모 촛불만 더한다. 대림 제1주일이 11월 안에 오면 그날부터 대림 장식이다.
3. **KST 고정.** 기기 시간대와 무관하게 한국 날짜로 계산한다(해외 사용자도 한국 달력을 따른다).
4. **성삼일 색**: 성목요일 백색, 성금요일 홍색, 성토요일 자색(미사가 없는 날이라 사순 색을 유지). 부활 성야부터는 다음 날(부활 대축일, 백색)로 넘어간다.
5. 한국 고유 전례력 가운데서는 **9월 20일 한국 순교 성인 대축일**만 넣었다(주일로 옮겨 지내는 경축 이동은 반영하지 않는다). 그 밖의 성인 축일·기념일은 다루지 않는다(평일은 시기 색).
6. 주님 봉헌(2/2), 성 요셉(3/19), 주님 탄생 예고(3/25), 성 베드로와 성 바오로(6/29) 등 옮김 규칙이 복잡하거나 장식이 달라지지 않는 날은 넣지 않았다.

## 2. 장식 목록

모든 시기 공통: **제대 앞 보**(전례 색 천 + 금 띠 + 금 십자가), 독서대가 있으면 **독서대 보**, 감실이 있으면 **감실 보**. 성 베드로 대성전은 제대가 콘페시오 뒤에 가려 앞에서 잘 보이지 않으므로 발다키노 앞 받침 두 곳에도 같은 색 **걸개 천**을 건다.

| 시기 | 색 | 장식 | 비고 |
|---|---|---|---|
| 대림 | 자색(3주일 장미색) | 대림환: 받침대 위 푸른 고리 + 초 넷(자색 셋·장미색 하나) | 주차만큼 초를 켠다(1~4). 먼저 켠 초가 더 짧다 |
| 성탄 | 백색 | 성탄 트리(방울 24·빛 점 40) + 구유(마구간·성모·요셉·아기 예수·양·별) + 포인세티아 화분 둘 | 선물 상자는 두지 않는다(전례 장식만) |
| 사순 | 자색(4주일 장미색) | 십자고상 가림천(있는 성당) + 자색 천을 두른 나무 십자가 | 꽃을 두지 않는다 |
| 성삼일 | 목 백색 / 금 홍색 / 토 자색 | 사순과 같되 성금요일은 **제대를 벗기고**(천 없음) 붉은 천 | |
| 부활 | 백색(성령 강림 홍색) | 부활초(금 촛대·큰 초·붉은 십자 표) + 흰 백합 화분 | 성령 강림 대축일은 천만 붉게 |
| 연중 | 녹색 | 천만(절제) | 대축일은 그날의 색 |
| 위령 성월 | 자색 기조 | 추모 촛불 탁자(두 단, 촛불 11개(간단 화질 6개), 흰 국화, 작은 십자가) | 11월의 연중 시기 동안 |

성당별 자리(`liturgy.js` `PLACES`): 주 제대(`altar`), 독서대(`ambo`: 우리 본당·피렌체·명동·성 바오로), 감실(`tab`: 우리 본당), 십자고상(`cross`: 우리 본당·피렌체·명동), 걸개 천(`banners`: 성 베드로), 시기 표지 자리 `L`(대림환·트리·십자가·부활초·추모 탁자), 구유 자리 `R`, 트리 자리 `T`(없으면 `L`), 화분 자리 `pots`.
큰 성당일수록 크게 짓는다(`k`: 우리 본당 1.15 ~ 성 베드로 1.6). 밀라노는 성가대석 사이가 좁아 제대 양옆에 0.6~0.7배로 두고(화분 없음), 명동은 왼쪽 설교대·오른쪽 독서대와 십자가를 피해 표지·구유를 제대 앞 왼쪽(난간 안)에, 트리를 설교대 뒤에 둔다.

- 장식은 **충돌체**를 가진다(걸어서 통과하지 않는다). 자리는 입구→제대 앞·촛불 봉헌대·성수대·14처·좌석으로 가는 길과 겹치지 않게 골랐고, `tools/church_web/liturgy.test.mjs`가 8개 성당 × 12개 상태에서 확인한다. 장식을 넣어도 스테이션(제대 앞·촛불·성수대) 자리는 변하지 않는다.
- 새 성당을 추가하면 `PLACES`에 자리를 넣어야 한다(없으면 장식 없이 그대로 보이고, 시험이 실패한다).

## 3. 그리기·성능

- 모두 **절차적 지오메트리**(텍스처·모델 파일 없음). 추가 용량은 `liturgy.js` 한 파일(약 30KB).
- 그리는 물체는 최대 3개: 천(전례 색, 약한 자체 발광) + 소품(성당 공용 재질 `mats.solid` 재사용) + 빛 점(`THREE.Points`, 촛불·트리 전구).
  높음 화질의 그리기 호출은 본 화면·바닥 반사(최대 2장)·AO 법선 패스를 합쳐 **+8 이하**(빛 점은 반사에 그리지 않는다), 보통·간단은 +3 이하.
- 정점: 연중 200~600, 사순 약 1천, 대림 약 5천, 부활·위령 약 8천~9천, 성탄 약 1만 2천(간단 화질은 5천 이하).
- 그림자를 드리우지 않는다(받기만). 시기를 바꾸거나 성당을 나가면 지오메트리·재질을 해제한다.
- 화질 단계가 바뀌면 다시 짓는다(간단 화질: 방울·잎·주름을 줄이고 전구 14개).

## 4. 앱 연결

- `LiturgicalDay.now()` → `toSceneArgs()` → `ChurchSceneController.setLiturgy()`(입장 직후, KST 자정 직후, 미리 보기 변경 때).
- 상태 칩 부제: `ChurchStatusChip(subtitle: …)`에 `chipLabel`(예: `사순 시기`, `연중 시기 · 위령 성월`, `주님 부활 대축일`).
- **미리 보기**: 설정 → 성당 → '전례 시기 미리 보기'(오늘 날짜·대림·성탄·사순·부활·연중·위령 성월). 고르면 열려 있는 성당의 장식과 칩이 바로 바뀐다. 저장하지 않으므로 앱을 다시 켜면 오늘 날짜로 돌아간다. 분석에는 `setting_change{key: church_liturgy_preview}`만 남긴다(고른 시기는 보내지 않는다).

## 5. 확인 방법

```
flutter test test/liturgical_season_test.dart test/church_liturgy_test.dart
node --test tools/church_web/liturgy.test.mjs
node tools/church_web/liturgy_shots.mjs --out <폴더> --churches stpeter,milan,basic --sheet
node tools/church_web/liturgy_perf.mjs --churches basic,stpeter,milan
```

브라우저에서 바로 보기: `assets/church/test.html?church=basic&liturgy=christmas`(`advent|christmas|lent|easter|ordinary|souls`, 대림 주차 `&lweek=3`).

## 6. 한계

- 빌더가 구워 넣은 기존 장식(우리 본당·성 바오로의 제대 옆 흰 꽃 등)은 사순 시기에도 남는다.
- 전례 색 조명(벽·창 빛의 색조)은 바꾸지 않는다. 천과 장식만 바뀐다.
- 가림천은 사순 시기 내내 씌운다(실제 관행은 사순 제5주일부터인 본당이 많다).
- 독서대·감실·십자고상이 빌더에 없는 성당(라테라노·성모 대성전·밀라노·성 베드로)은 제대 앞 보와 시기 표지만 바뀐다.

## 7. 인수인계 (2026-11-14 중단 시점)

### 끝난 것

- 전례 달력 도메인(`lib/domain/liturgical_season.dart`) + 단위 시험(2024~2040, KST 경계, 미리 보기 대표 날).
- 3D 장식(`assets/church/liturgy.js`): 8개 성당 전부에 자리 표가 있고 12종 장식이 모두 지어진다. `main.js`·`bridge.js`·`index.html`·`test.html` 연결 완료.
- Flutter 연결: `ChurchSceneController.setLiturgy`, `ChurchLiturgyBinding`(입장·KST 자정·미리 보기 변경 때 전송), 상태 칩 부제(`ChurchStatusChip.subtitle`), 설정 → 성당 → '전례 시기 미리 보기'.
- 시험: `tools/church_web/liturgy.test.mjs`(13개), `test/liturgical_season_test.dart`(8개), `test/church_liturgy_test.dart`(6개).
- 눈으로 확인한 성당: 성 베드로·밀라노·명동·우리 본당 × 6개 시기(낮), 우리 본당 밤(21시) 3종.
- 그리기 호출: 우리 본당 높음 화질에서 대림·성탄 **+8**(예산 한도) 실측.

### 남은 것

- **피렌체·라테라노·성모 대성전·성 바오로는 스크린샷으로 확인하지 못했다.** 자리는 충돌·경로 시험만 통과한 상태다(제대·난간에 파묻히거나 가려지는지는 눈으로 봐야 한다).
- **프레임 시간 전/후 비교(±5%)는 결론을 내지 못했다.** 측정 중 기기 부하(load 20, 프레임당 1.5~2초)가 커서 숫자가 흔들렸다(대림 +0.2%, 성탄 +24%: 신뢰할 수 없음). 누수 검사(`liturgy_perf.mjs`의 '해제 뒤' 줄)도 브라우저가 중간에 닫혀 끝까지 돌지 못했다(Node 시험의 지오메트리 해제 검사는 통과).
- 깜빡임 검사(`liturgy_flicker.mjs`)는 작성만 하고 **한 번도 끝까지 돌리지 못했다.**
- 간단 화질(low) 스크린샷 미확인.
- 상태 칩의 **전례 색 점(●)**: HUD 의 `subtitle`이 문자열 하나라 색 점을 넣지 못했다. `LiturgicalColorDot`·`liturgicalColor()`는 준비돼 있다(HUD 쪽에 앞머리 위젯 자리가 필요).
- `tools/church_web/liturgy_shots.mjs`의 처음 대기 프레임을 6→24로 바꾼 뒤에는 다시 찍지 않았다(지금 `shots/`의 대림 사진은 카메라가 덜 안착한 구도).

### 다음 첫 3가지

1. `node tools/church_web/liturgy_shots.mjs --out <폴더> --churches florence,lateran,maggiore,stpaul --sheet` 로 네 성당을 찍어 보고 `PLACES`의 `L`/`R`/`pots`를 고친다(고친 뒤 `node --test tools/church_web/liturgy.test.mjs`).
2. 기기가 한가할 때 `node tools/church_web/liturgy_perf.mjs --churches basic,stpeter,milan` 과 `--quality low` 를 끝까지 돌려 프레임 시간·누수 줄을 이 문서 §3에 적는다. 이어서 `node tools/church_web/liturgy_flicker.mjs basic milan`.
3. 자색 색감을 정한다: 지금 `0x7440ad` + 발광 0.2 는 어두운 성당(성 베드로)에서는 알맞고 밝은 우리 본당에서는 조금 연하다. 조명 작업(룩 프리셋)이 끝난 뒤 한 번에 맞춘다.

### 주의

- `PLACES`는 빌더(`ch_*.js`)의 제대 좌표를 **옮겨 적은 값**이다. 빌더에서 제대·독서대·십자고상을 옮기면 표도 같이 고쳐야 한다.
- 빛 점은 레이어 1을 쓰고, `liturgy.js`가 본 화면 카메라(`__church.camera`)에 레이어 1을 켠다. 다른 코드가 레이어 1을 쓰기 시작하면 겹친다.
- 장식 충돌체는 `world.logic.colliders`에 직접 넣고 뺀다. 경로 탐색 격자는 장식을 모르므로, 자리를 옮길 때는 반드시 시험(걷는 길과 겹치지 않음)을 돌린다.
- 성당 화면 시험은 오늘 날짜의 칩 부제를 그대로 쓴다. 날짜에 따라 글자가 달라지므로 부제 글자를 단언하는 시험은 `ChurchLiturgy.clock`을 고정한다(`test/church_liturgy_test.dart` 참고).
- 장식을 끄려면 Flutter 에서 `setLiturgy`를 보내지 않거나 `{season: 'none'}`을 보내면 된다(웹 기본값은 장식 없음).
