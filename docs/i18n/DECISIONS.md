# 다국어 결정 (2026-11-23, 사용자)

- 언어 순서: 영어(필수) → 라틴어 토글 → 스페인어 → 이탈리아어. 포르투갈어는 **승인을 받은 뒤** 넣는다(그 전에는 ReleaseGate 뒤에서 준비만).
- 기도 언어 = 화면 언어. 따로 고르는 칸은 두지 않는다. 예외는 설정의 「라틴어로 기도」 켜기 하나(기본 끔).
- 한국어가 아닌 기도문과 라틴어는 **글로만** 보여 준다(소리로 읽지 않음). 한국어 선창 음성은 그대로.
- 기도문은 한국어를 옮기지 않는다. 언어·나라 변종별 공식 본문을 출처·허락 상태와 함께 싣는다.
- 외국어 앱 이름: **Rosarium**.
- 이미 설치한 사용자는 **한국어 고정**(새 설치만 폰 언어를 따름).
- 미국 주교회의(USCCB) 누리집이 막혀 영어 기도문 본문을 확인하지 못했다 → 허락 요청 편지에서 **공식 영어 본문 자체를 요청**한다(es·it·pt도 확인 안 된 것은 같은 방식).
- 독서공방(reading-journal) 번역은 겹치는 약 135개만 재사용하고, 절차·가드 시험 개념을 옮겨 쓴다.
