# 독서공방에서 무엇을 재사용할 수 있나

> 작성: Claude Opus 5.5 · 측정일 2026-11-23(UTC) · 대상: 로사리움 UI+DYN 고유 문자열 1,634개(inventory.md) ↔ 독서공방 `i18n/strings.tsv` (8,992줄, 열 `key ko en de es pt ja zh-tw id vi tr`). 독서공방 파일은 읽기만 했다.

## (a) 문자열 겹침 — 실측

방법(`tools/overlap.py`, 결과 전체 `tools/overlap.tsv`):
1. **정확 일치**: 양쪽의 자리표시(`{n}`·`${x}`·`{}`)를 `{}`로 맞추고, `\n` 이스케이프와 HTML 태그를 정리한 뒤 문자열이 같은 것.
2. **정규화 일치**: 위에 더해 공백·문장부호(. , ! ? … · : 괄호 따옴표 「」 등)와 이모지를 지운 뒤 같은 것.
3. **근사**(참고용): 정규화 문자열 길이 6자 이상, `difflib` 유사도 0.85 이상.
4. **번역 메모리 후보**(참고용): 유사도 0.70 이상(8~80자).

- **글자 수로 보면 2.0%**(일치 647자 / 33,044자)다. 일치한 문자열은 평균 4.4자인 짧은 버튼·라벨(취소·닫기·저장·다음·확인·최근 30일 등)이고, 안 맞은 것은 평균 21.7자다. 번역 작업량은 **약 2~3%만 줄어든다**.
- **문맥 검사 결과 거짓 친구 12개.** 한국어는 같지만 뜻이 다르다. 그대로 넣으면 오역이다:
  - 요일을 다른 뜻으로 번역한 것: `금`(Gold ← 금요일이어야), `월`(Month ← 월요일), `일`(days ← 일요일)
  - `첫`(First, 문맥 미상), `초`(sec ← 「세기 초」, 실은 유리창 연도 파서라 화면 문구가 아닐 수도 있다)
  - `보기`(Appearance), `{} 보기`(Show {books}), `가져오기`(Bring them back ← 백업 가져오기는 Import), `오른쪽`(Right page), `계정`(「(account)」)
  - 근사 일치 `공유하지 못했어요…`가 독서공방의 「저장하지 못했어요」에 붙은 것, `비밀번호는 {} 이상`이 「6 characters」를 박아 둔 것

  → **문맥이 맞는 것은 약 135개**(UI의 약 8%). 이 겹침은 **「후보 표」로만 쓰고, 키마다 호출 자리를 보고 채택**해야 한다(독서공방 add-language §5 「호출부를 열어 확인한다」와 같은 원칙).

**한계.** 독서공방 시험은 단일 HTML을 문자열로 읽고 DOM을 렌더한다. 로사리움 Dart에는 **개념만** 옮기고 구현은 새로 짠다. 그 대신 `gen-l10n`이 정적 키 누락을 컴파일 시점에 잡으므로 독서공방의 「동적 키(`tr('x.'+v)`)」 사고는 Dart 쪽에서 구조적으로 줄어든다. 남는 동적 키 위험은 enum→문구 `switch`와 WebView JS 쪽이다.
