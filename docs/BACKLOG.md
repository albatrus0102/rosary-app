## 출시 전 확인
- 앱 이름 '로사리움' 스토어·상표 중복 확인, 부제 '3D 가상 성당'
- 사제·교구 검수: 십자가의 길 묵상 문구(docs/ux/STATIONS_OF_CROSS.md), 기도문·선창/후창 분할
- **십자가의 길 대체 성화(2026-11-14)**: 프레비아티 연작(성 베드로 대성전에 배정, 사진 Sailko CC BY 3.0)은 바티칸 박물관 소장품 촬영물 이용 규정을 확인하지 못했다 → 출시 전 확인, 안 되면 다른 연작으로 교체. CC BY 표기(촬영자·라이선스 링크·변경 여부)는 앱 안(묵상 시트·성화 출처)에 유지해야 한다. 코로 도판 촬영자·모슬러 생몰년·1897년 석판화 삽화가는 미확인(docs/ux/STATIONS_OF_CROSS.md '위험')
- 이탈리아 문화유산법·사진 권리 검토(스테인드글라스 사진, 시스티나 도입 시 그림 사진)
- 서버(Cloudflare)·Supabase 배포와 실서버 통신 검증(접속자 시트, 무릎 꿇기 전파 `k`, 상태 복원 재접속)
