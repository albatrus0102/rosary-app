## 출시 전 확인
- 앱 이름 '로사리움' 스토어·상표 중복 확인, 부제 '3D 가상 성당'
- 사제·교구 검수: 십자가의 길 묵상 문구(docs/ux/STATIONS_OF_CROSS.md), 기도문·선창/후창 분할
- **교구 허락 — 『가톨릭 기도서』 기도문 게재(2026-11-15)**: 십자가의 길 공식 기도문 전문(시작 기도·14처 기도·계응, `data/stations_prayers.json`)과 묵주기도 기도문(`lib/domain/prayer_data.dart`)은 한국천주교주교회의 저작물이다. 주교회의 저작권 안내(https://cbck.or.kr/Copyright)는 『가톨릭 기도서』 내용의 전재·복제에 승인을 요구한다 → 출시 전 「저작권 사용 승인 신청서」로 서면 신청(한국천주교중앙협의회 총무부 02-460-7552, mano@cbck.or.kr). 허락 전에는 출처·판본·저작권 표기(묵상 시트 아래 한 줄, 더보기 '기도문 출처')를 유지한다. 허락을 못 받으면 십자가의 길은 공식 기도문을 빼고 접힌 '묵상'(앱 글)만 남기는 것으로 되돌린다. 미확정: 십자가의 길 마침 기도(공식 본문에 없음 — 앱 글을 '공식 기도문 아님'으로 밝혀 둠), 제목 표기 '사도신경'/'묵주기도'(공식은 '사도 신경'/'묵주 기도'), `┼`·`◎` 기호의 실기기 글꼴 표시(Pretendard 에 없어 기기 글꼴로 대체). 대조표 docs/church/PRAYER_VERIFICATION.md
- **십자가의 길 대체 성화(2026-11-14)**: 프레비아티 연작(성 베드로 대성전에 배정, 사진 Sailko CC BY 3.0)은 바티칸 박물관 소장품 촬영물 이용 규정을 확인하지 못했다 → 출시 전 확인, 안 되면 다른 연작으로 교체. CC BY 표기(촬영자·라이선스 링크·변경 여부)는 앱 안(묵상 시트·성화 출처)에 유지해야 한다. 코로 도판 촬영자·모슬러 생몰년·1897년 석판화 삽화가는 미확인(docs/ux/STATIONS_OF_CROSS.md '위험')
