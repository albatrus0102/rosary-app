# 영상 계획 — 잉글랜드·웨일스 주교회의 전례국(Liturgy Office, CBCEW) (prayer-cbcew)

- 자막 언어: **영어** · 길이 약 1분 36초(1~2분) · 변종: en-GB(·IE)
- 찍는 것: **한국어판 앱 화면.** 답을 받기 전에는 그쪽 본문을 앱에 넣지 않으므로, 본문이 들어갈 자리와 쓰는 방식을 한국어 화면으로 보여 주고 자막으로 설명한다. 영상에 그쪽 기도문 본문을 적지 않는다.
- 만드는 법: 화면 녹화(세로 화면을 16:9 틀 가운데에 둠), 1080p, 해설 목소리 없음, 자막만. 한국어 선창 음성은 8번 장면에서만 2~3초 들려 준다(배포판 상태: 기기 음성).
- 올리는 법: YouTube **일부 공개(unlisted)**, 제목 `Rosarium — prayer screens (English)`. 설명 칸에 개인 정보를 적지 않는다. 주소는 편지·요약의 〔YouTube 링크〕 자리에 넣는다.
