# 동의 화면 동작 규칙 (A2 구현 참고)

1. 필수 3개는 각각 체크박스(또는 "필수 모두 동의" 한 개 + 개별 펼침)로 받되, **선택 4개는 필수와 시각적으로 분리**하고 기본값은 **모두 해제**입니다. "전체 동의" 버튼이 있어도 선택 항목을 자동으로 켜지 않습니다(필수만 켜는 버튼은 가능).
2. 선택 항목을 하나도 켜지 않은 채 [시작하기]를 눌러도 진행되어야 합니다.
3. `consentVersion`이 저장된 값과 다르면 다시 동의 화면을 보여 줍니다.
4. 동의·철회 때마다 `set_consent(kind, granted, version, source)`를 호출합니다 (`source` = `app`).
5. 계정 화면의 선택 동의 토글은 끄는 즉시 `set_consent(kind, false, ...)`를 호출하고, "서버에 저장된 이 범주의 데이터가 삭제됩니다"를 안내합니다.
6. 화면 문구의 [자세히 보기]에는 위 표(수집·이용 목적, 수집 항목, 보유·이용 기간, 거부 권리와 불이익, 철회 방법)와 '수집하지 않는 정보'를 그대로 보여 줍니다.
