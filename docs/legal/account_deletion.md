# 계정 삭제 안내

## 1. 앱에서 삭제하기 (권장)

1. 앱을 열고 **설정 > 계정** 으로 이동합니다. (실제 메뉴 이름은 앱 화면과 일치하는지 **확인 필요**)
2. 맨 아래 **계정 삭제** 를 누릅니다.
3. 안내 내용을 확인하고 한 번 더 **삭제** 를 누릅니다. (필요하면 다시 로그인하도록 요청할 수 있습니다.)

삭제를 확인하면 **즉시** 서버의 계정과 데이터가 삭제됩니다. 되돌릴 수 없습니다.

## 2. 무엇이 삭제되나요

| 구분 | 처리 |
|---|---|
| 로그인 정보(이메일, 로그인 수단, 소셜 식별값, 비밀번호 값) | 삭제 |
| 프로필(가입·접속 시각, 언어) | 삭제 |
| 동의 이력 | 삭제 (보관 필요성은 법률 검토 후 확정 — 보관하게 되면 이 문서와 처리방침에 기간·항목을 적습니다) |
| 화면·기능 사용 기록, 성당 이용 기록, 오류 기록 | 삭제 |
| 기기 정보 | 삭제 |
| 서버의 기도 기록 | 삭제 |
| 이 기기에 저장된 기도 기록·설정 | **서버 삭제와 별개로 기기에 남습니다.** 앱 삭제 또는 앱 데이터 삭제로 지울 수 있습니다. |
| 서비스 제공자의 백업·로그 | 일정 기간 뒤 순차적으로 사라집니다. 기간: {{백업 보관 기간 — Supabase 설정에 따라 확인 필요}} |
| 카카오·구글 쪽 계정 | 그대로 유지됩니다. 연결도 끊으려면 각 서비스의 설정에서 "연결된 앱"에서 이 앱을 제거하세요. |

## 3. 삭제하기 전에

- 내 데이터를 받아 두려면 **설정 > 계정 > 내 데이터 내려받기** 를 먼저 사용하세요.
- 계정만 지우지 않고 **선택 동의만 철회**해도 해당 범주의 서버 데이터가 즉시 삭제됩니다(설정 > 계정 > 선택 동의).

## 5. 자주 묻는 질문

- **삭제한 뒤 다시 가입할 수 있나요?** 가능합니다. 새 계정으로 시작하며 예전 데이터는 복구되지 않습니다.
- **로그인만 해제하고 싶어요.** 설정 > 계정 > 로그아웃을 사용하세요. 서버 데이터는 그대로 있습니다.
